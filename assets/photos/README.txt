FOTOGRAFIE PUBBLICHE - SOLO COPIE WEB CON TAG
===========================================
full/ contiene le copie WebP principali delle fotografie pubblicate.
thumbs/ contiene la miniatura WebP derivata dalla STESSA immagine firmata.
cover/ puo' contenere una copertina dedicata quando il crop non deve comparire
nella galleria. "full" non significa master/full quality.

Il sito non deve mai contenere RAW/FQ, export puliti o cartelle originali,
neppure fuori dal catalogo. Tienili altrove, non nel repository pubblico.
Non ci sono link ai master ne' un pulsante per scaricare una versione pulita.
Lo zoom 100% mostra solo i pixel del file web gia' disponibile al visitatore.

Il watermark/tag deve essere gia' incorporato nei pixel del file di partenza.
Il preparatore non lo aggiunge, non lo rimuove e non lo riconosce: usalo su
una copia GIA' FIRMATA, confermandolo con --watermarked.

Percorsi consigliati:
  assets/photos/ID-ALBUM/full/CODICE.webp
  assets/photos/ID-ALBUM/thumbs/CODICE.webp
  assets/photos/ID-ALBUM/cover/CODICE-COVER.webp   (solo se serve)

Una cartella/file da sola non aggiunge foto: compila photos.js e albums.js.
Le immagini pubblicate sono accessibili; il tag non e' un blocco tecnico.
