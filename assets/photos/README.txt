FOTOGRAFIE PUBBLICHE - SOLO COPIE WEB CON TAG
===========================================
full/ contiene le copie WebP principali quando una raccolta usa il workflow nuovo.
large/ resta supportata per raccolte legacy con JPG gia' pubblicati (es. Noale).
thumbs/ contiene la miniatura WebP della STESSA immagine firmata.
"full" o "large" non significa master/full quality.

Il sito non deve mai contenere RAW/FQ, export puliti o cartelle originali,
neppure fuori dal catalogo. Tienili altrove, non nel repository pubblico.
Non ci sono link ai master ne' un pulsante per scaricare una versione pulita.
Lo zoom 100% mostra solo i pixel del file web gia' disponibile al visitatore.

Il watermark e' incorporato nei pixel dei file di partenza, non sovrapposto
con CSS. Il preparatore non lo aggiunge, non lo rimuove e non lo riconosce:
usalo su una copia GIA' FIRMATA, confermandolo con --watermarked.
Controlla anche la leggibilita' del tag nella miniatura.

Percorsi consigliati: assets/photos/ID-ALBUM/full/CODICE.webp
                     assets/photos/ID-ALBUM/thumbs/CODICE.webp
Una cartella/file da sola non aggiunge foto: compila photos.js e albums.js.
Le immagini pubblicate sono accessibili; il tag non e' un blocco tecnico.

AGGIUNTA / JESOLO 2026
